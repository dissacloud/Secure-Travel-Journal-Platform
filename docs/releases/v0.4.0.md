# v0.4.0 — Secure AWS Runtime Platform

Phase 4 introduces the secured AWS runtime environment for the Secure
Travel Journal Platform.

## Capabilities

- encrypted and versioned Terraform remote state;
- native S3 Terraform state locking;
- multi-AZ VPC;
- public, private and isolated database trust zones;
- Regional NAT Gateway;
- encrypted VPC Flow Logs;
- Amazon EKS Auto Mode;
- private EKS application subnets;
- restricted Kubernetes API access;
- EKS Access API authorization;
- explicit administrator access entries;
- EKS control-plane logging;
- Amazon RDS PostgreSQL;
- Multi-AZ database deployment;
- customer-managed RDS KMS encryption;
- RDS-managed Secrets Manager credential;
- TLS-enforced PostgreSQL;
- IAM database authentication;
- EKS Pod Identity;
- dedicated backend NodeClass and NodePool;
- separate Pod network identity;
- SG-to-SG database authorization;
- Restricted Pod Security Admission;
- default-deny Kubernetes NetworkPolicy;
- least-privilege database bootstrap identity;
- automated platform validation;
- positive and negative authorization testing.

## Deployment boundary

Phase 4 provides infrastructure only.

Application images are not rebuilt or deployed by this milestone.

Future application deployment must consume the immutable trusted
container digests created during Phase 3.
