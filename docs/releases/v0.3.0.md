# v0.3.0 — Trusted Software Supply Chain

Phase 3 introduces trusted artifact production and verification.

## Capabilities

- GitHub Actions OIDC federation to AWS
- Short-lived AWS credentials
- Least-privilege trusted build IAM role
- Immutable Amazon ECR repositories
- Build-once container workflow
- Pre-publication Trivy enforcement
- Git-SHA artifact tags
- OCI digest-based artifact identity
- SPDX SBOM generation
- CycloneDX SBOM generation
- SLSA build provenance
- SPDX SBOM attestation
- CycloneDX SBOM attestation
- Cosign keyless image signing
- Separate read-only artifact verifier role
- Signature identity verification
- Provenance verification
- Source repository/ref/commit verification
- Fail-closed artifact trust gate
- Controlled negative verification test

## Security model

Pull requests remain untrusted and receive no cloud or signing authority.

Only code merged to protected `main` may produce trusted release
artifacts.

Future deployments will promote an existing verified ECR digest rather
than rebuilding the application.
